303 Superheroes

Eight weeks of network science, run on one small corner of Wikipedia.

Wikipedia's category of Marvel Comics superheroes holds 303 characters. Whenever one character's article links to another's, that's an edge — 1,784 of them, all pointing one way. That network is the shared playground for our whole course, and this site is where we take it apart.

Every week we publish one post: a question we got curious about, the code we ran, at least one figure, and what actually surprised us. The dataset stays frozen so every group in the class computes on identical data; what changes each week is the set of tools we're allowed to point at it. Early on that means degrees, distances and communities. From week 5 we stop looking at the links and start reading the text.

We write these in Jupyter with an agentic coding assistant, and we check its work — one running theme here is which numbers we trusted, which ones we verified by hand, and the times the two disagreed.
